## Project Overview

**mw-dev** is a development version of the MW (Monier-Williams) dictionary pipeline, used for collaboration with [Andhrabharati](https://andhrabharati.com/). It provides a local build environment for generating and testing MW dictionary outputs independently of the main Cologne pipeline.

## Architecture

| Directory | Purpose |
|---|---|
| `orig/` | MW source digitization files (copied from `csl-orig/v02/mw/`) |
| `pywork/` | Build scripts for headwords, XML, and SQLite (generated by `csl-pywork`) |
| `web/` | Web display files |
| `downloads/` | Generated download archives |
| `abcode/` | Andhrabharati-specific code and integration work |

### Purpose

This repo allows development of MW-specific changes (abbreviation markup, headword normalization, display tweaks) in isolation, with the ability to test against the Andhrabharati display before applying changes to the main Cologne pipeline.

## Common Commands

### Build headwords and XML (from `pywork/`)
```bash
sh redo_hw.sh
sh redo_xml.sh
```

## Dependencies

- **Python 3**
- **csl-orig** sibling repo — MW source data
- **csl-pywork** sibling repo — build scripts
